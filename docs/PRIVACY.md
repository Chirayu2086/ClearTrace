# ClearTrace privacy notes

ClearTrace stores settings and tracker-domain observations in Chrome local extension storage. URL checks run locally. The current implementation does not configure remote analytics, accounts, or a threat-intelligence API. Optional tracker blocking requires permission to access HTTP and HTTPS sites.

Before publishing, replace this document with a reviewed policy that includes the publisher's contact information and a public policy URL. Describe the final implementation accurately and update disclosures if remote services are added.
