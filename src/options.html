What ClearTrace checks

  • Tracker awareness: checks script, iframe, image and link elements for a small set of known third-party tracker domains.
  • Suspicious links: checks URL structure for common warning signs such as embedded credentials, punycode, IP-hosted URLs and unusual hostname patterns.
  • Local-first: link inspection happens inside the extension. No reputation API or browsing data upload is configured.

Limitations

ClearTrace is not antivirus software and does not query a live threat-intelligence database. Tracker detection is best-effort and only sees known domains represented in page elements; tracker blocking is limited to the built-in list. A clean result never guarantees a URL is safe.
